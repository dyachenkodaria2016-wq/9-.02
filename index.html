Це навчальний браузерний симулятор, а не повна копія Microsoft Access. Дані зберігаються у браузері лише протягом поточної сесії, якщо не експортувати резервну копію.

Швидкий старт

  1. Перейдіть у «Таблиці» та оберіть таблицю.
  2. У «Конструкторі запитів» виберіть будь-яке поле, оператор і значення.
  3. Натисніть «Виконати запит» — результат з'явиться нижче.
  4. У «Імпорт та експорт» збережіть JSON-резервну копію або CSV для Access.

Імпорт та експорт

Важливо про .accdb: цей статичний сайт не створює справжній файл Microsoft Access (.accdb). Перейменування JSON/CSV на .accdb не працює й спричиняє помилку «file is not a database». Для Access підготовлено CSV-експорт таблиць і JSON-резервну копію.

Експорт

Імпорт

Передавання до Microsoft Access

  1. Натисніть «Експортувати всі таблиці (CSV)» — буде завантажено окремий CSV для кожної таблиці.
  2. У Microsoft Access створіть порожню базу даних або відкрийте наявну.
  3. Оберіть «Зовнішні дані» → «Створити джерело даних» → «З файлу» → «Текстовий файл» (назви пунктів можуть відрізнятися залежно від версії).
  4. Виберіть CSV, імпортуйте дані в нову таблицю та позначте, що перший рядок містить імена полів.
  5. Для кожної таблиці повторіть імпорт. За потреби в Access задайте первинний ключ і зв'язки вручну.
  6. Збережіть базу в Access як .accdb — цей файл уже створить сама програма Microsoft Access.

CSV переносить значення полів, але не переносить автоматично типи, ключі, зв'язки, форми, запити та звіти. JSON зберігає структуру навчального симулятора для повторного імпорту саме сюди.

Інструкція користувача

1. Створення запиту

  1. Відкрийте «Конструктор запитів».
  2. Оберіть таблицю. Список полів завантажується з її фактичної структури.
  3. Натисніть «Додати умову», виберіть поле, оператор і значення.
  4. Для тексту використовуйте «містить», «дорівнює», «починається з»; для чисел — порівняння; для дат — дорівнює/раніше/пізніше.
  5. Виберіть AND, щоб виконалися всі умови, або OR, щоб виконалася хоча б одна.
  6. Натисніть «Виконати запит». Якщо результат порожній, перевірте значення та тип поля.

2. Редагування даних

У розділі «Редагування даних» можна додати новий запис. Для навчального прикладу доступні таблиці «Учні» та «Оцінки».

3. Резервна копія

JSON зберігає всі таблиці, поля та записи й може бути імпортований назад у симулятор. Зберігайте резервну копію перед оновленням сторінки.

4. Обмін із Microsoft Access

Для обміну використовуйте CSV. Імпортуйте кожну таблицю в Access, перевірте типи полів, налаштуйте ключі та зв'язки й збережіть результат як .accdb безпосередньо в Access.

Не завантажуйте CSV або JSON у Access, перейменувавши їх на .accdb. Це різні формати файлів.
