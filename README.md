# Access Lab — навчальний симулятор баз даних, 9 клас

Це оновлена версія попереднього проєкту Access Lab. Збережено початковий дизайн, бордову палітру, структуру розділів і демонстраційні таблиці. Виправлено та розширено роботу конструктора запитів.

## Робота з конструктором запитів
1. Відкрийте **Конструктор запитів**.
2. Оберіть таблицю.
3. Натисніть **+ Додати умову**.
4. Для кожної умови виберіть поле, оператор і значення.
5. Виберіть **Усі умови (AND)** або **Будь-яка умова (OR)**.
6. Натисніть **Виконати запит**. Результат з'явиться в таблиці нижче.

Підтримуються текстові умови (дорівнює, не дорівнює, містить, починається з, закінчується на), числові й датовані порівняння (дорівнює, не дорівнює, більше, не менше, менше, не більше), а також перевірки на порожнє/непорожнє значення. Перевіряється коректність чисел і дат; повідомлення пояснює, чому запит не виконався або чому результат порожній.

## Публікація на GitHub Pages
1. Завантажте `index.html`, `README.md` і папку `.github` у корінь репозиторію.
2. Зробіть Commit у гілку `main`.
3. У **Settings → Pages** перевірте, що Source — **GitHub Actions**.
4. Відкрийте **Actions** і дочекайтеся завершення `Deploy to GitHub Pages`.

Workflow має дозвіл автоматично активувати GitHub Pages, якщо це дозволяє політика репозиторію/організації.

## Важливо про Microsoft Access
Цей сайт є навчальним браузерним симулятором і не створює справжні файли `.accdb`. Для обміну з Microsoft Access використовуйте CSV-експорт; JSON призначений для резервної копії саме цього симулятора.
